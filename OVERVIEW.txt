┌─ 📈 STRATÉGIES DE DÉPLOIEMENT ───────────────────────────────────────────────────┐

🌑 SHADOW (Défaut - SÛRE)
   Client → API → v1 (retourné) ✅
                + v2 (tracé en parallèle) 📊
   
   ✅ Zéro risque utilisateur
   ✅ Comparison réelle en production
   ✅ Easy rollback

🐤 CANARY (Progressif)
   Client → API → 90% v1 ✅
                + 10% v2 🐤
   
   ✅ Impact limité
   ✅ Détection rapide d'erreurs
   ✅ Montée en charge progressive

🚀 PRODUCTION (Complet)
   Client → API → v2 remplace v1
   
   ✅ Remplacement complet
   ⚠️  À utiliser après validation

🔄 ROLLBACK (Retour)
   Client → API → Retour à v1
   
   ✅ Annule le déploiement

┌─ 📊 MÉTRIQUES TRACÉES ────────────────────────────────────────────────────────────┐

Accuracy:   Score de classification globale
Precision:  Proportion de prédictions positives correctes
Recall:     Proportion de cas positifs détectés
F1-Score:   Moyenne harmonique de precision et recall
Confusion Matrix: Matrice des erreurs
Classification Report: Rapport détaillé par classe

Sauvegardées dans: artifacts/v*/metrics.json
